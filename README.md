# Hospital Analytics

This project catches hospital admission messages, cleans them, and organizes them into report-ready tables (bronze → silver → gold).

**The full guide is in the [`docs`](docs/) folder.** Start with the [overview](docs/00-overview.md), then follow the steps in order. Steps 8 and 9 are optional.
